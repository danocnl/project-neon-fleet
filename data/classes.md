# Class Specializations — Project Neon Fleet

9 class specializations acting as the software logic layer on top of a ship chassis.
Each class has unique primary tags, shared secondary tags (max 3 classes per tag),
and draft tag weightings (1 = occasional, 5 = core class identity).

Synergy ratings: S = exceptional · A = good · B = workable · C = poor

---

## Chrono Architect
**Role:** Support / Utility
**Identity:** Time distortion and cooldown reduction. Accelerates ally execution loops.

**Primary Tags (unique):** CHRONO · EXECUTION_SPEED · TEMPORAL_ECHO
**Secondary Tags (shared):** COOLDOWN · FREQUENCY · ON_KILL

**Draft Tag Weighting:**
```
CHRONO           5  (core)
EXECUTION_SPEED  5  (core)
TEMPORAL_ECHO    4
COOLDOWN         4
FREQUENCY        3
ON_KILL          2
```

**Co-op Synergy:** Creates temporal acceleration bubbles that allow nearby allies to execute weapon reload and auto-logic loops up to 50% faster.

**Recursive Draft Focus:** Cooldown reductions, time distortion fields, faster automated loop triggers, effect duplication via temporal echo.

**Best Ships:** Sidewinder (S) · Anaconda (S) · Cobra (A) · Python (A)
